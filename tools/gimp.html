What it is

A free, open-source photo editor for your computer: retouching, layered graphics, and digital painting, like Photoshop without the subscription. Open source means the program's code is public, and nobody can move it behind a paywall later. GIMP stands for GNU Image Manipulation Program.

Pricing model

Completely free. There is no paid version, no account, no subscription, and no watermark. It is free for personal work and paid client work alike.

What the free plan gives you

  • Everything: layers, masks, brushes, and photo retouching
  • Scripted batch work, which means repeating the same edit on many files automatically
  • Digital painting and layered graphics
  • Free for personal work and paid client work alike

Free-plan limitations

  • The interface takes time to learn, and it does not look as polished as paid editors
  • There is no browser version and no cloud sync; it is installed software on your computer
  • Download it only from the official site, gimp.org. If any website asks you to pay for GIMP itself, it is not the official source
