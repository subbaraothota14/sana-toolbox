Microsoft OneDrive

Freemium Storage

Microsoft's cloud storage, built into Windows: your Desktop, Documents, and Pictures folders backed up online, with the web versions of Word, Excel, and PowerPoint.

Pricing model

Freemium. Free, $0 for one person. The paid step is Microsoft 365 Basic: 100 GB for $1.99 a month or $19.99 a year (checked November 2026). Microsoft 365 Personal is 1 TB for $99.99 a year, and it includes the desktop Office apps.

What the free plan gives you

  • 5 GB of free storage per Microsoft account
  • Sync on Windows, Mac, iPhone, Android, and the web
  • File sharing by link
  • Personal Vault, an extra-protected folder for sensitive files
  • Built into Windows 10 and 11, so turning on folder backup takes a few clicks

Free-plan limitations

  • 5 GB is small, and it is shared with Outlook.com attachments and items in the Recycle Bin
  • If you go over 5 GB, OneDrive stops syncing new files and Outlook.com stops sending and receiving email
